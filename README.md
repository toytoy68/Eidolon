# Project Eidolon

<p align="center">

Project Eidolon is an open engineering journal documenting the design and development of a modular artificial intelligence platform running entirely on local hardware.

## Goals

- 100% local AI
- No cloud dependency
- Long-term memory
- Multi-agent orchestration
- Robotics integration
- Local speech recognition and TTS
- Computer vision
- Modular architecture

## Current Hardware

### AI Server

- Intel Core i5-14500
- 64 GB DDR4 (128 GB planned)
- NVIDIA Tesla V100 SXM2
- Proxmox VE
- Debian
- Ollama

## Current Progress

- ✅ Tesla V100 successfully validated
- ✅ CUDA and Ollama operational
- ✅ Gemma 4 benchmark completed
- ✅ Qwen3 MoE benchmark completed
- 🚧 Dual V100 NVLink platform
- 🚧 Memory architecture
- 🚧 Agent orchestration
- 🚧 Robotics platform

## Philosophy

Eidolon is designed as a fully autonomous local AI system capable of reasoning, remembering, interacting with its environment and controlling robotic platforms without relying on cloud services.

Every experiment, benchmark and engineering decision is documented in this repository.
